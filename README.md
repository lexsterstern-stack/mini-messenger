# Mini Messenger

Свой мессенджер: регистрация, вход, каналы, сообщения в реальном времени
через WebSocket, хранение в SQLite. Трафик идёт по HTTPS/WSS после деплоя —
это и есть шифрование соединения.

## Деплой с телефона — пошагово

### Шаг 1. Залить код на GitHub

1. Открой github.com в браузере телефона, зайди или зарегистрируйся.
2. Нажми **+** вверху → **New repository**.
3. Имя — например `mini-messenger`, Public или Private — не важно. **Create repository**.
4. На странице репозитория нажми **Add file → Upload files**.
5. Загрузи ВСЕ файлы из этого проекта, сохраняя структуру папок
   (`server.js`, `package.json`, `.gitignore`, `README.md`, и папку `public`
   со всеми тремя файлами внутри). GitHub позволяет перетащить/выбрать
   сразу несколько файлов — папку `public` придётся загружать, зайдя в неё
   отдельным шагом («Create new file» → ввести `public/index.html` как имя,
   это создаст папку автоматически, затем так же для `app.js` и `style.css`).
6. Внизу — **Commit changes**.

### Шаг 2. Задеплоить на Render.com

1. Открой render.com, зарегистрируйся (можно через GitHub — тогда шаг
   авторизации пройдёт в одно касание).
2. **New +** → **Web Service**.
3. Выбери свой репозиторий `mini-messenger` (Render попросит доступ к
   GitHub — разреши).
4. Настройки:
   - **Name**: любое
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
5. В разделе **Environment Variables** добавь:
   - `JWT_SECRET` — любая длинная случайная строка (придумай сама, это
     секрет для подписи токенов входа)
6. **Create Web Service** — подожди 2-5 минут, пока соберётся.
7. Когда статус станет **Live**, вверху будет ссылка вида
   `https://mini-messenger-xxxx.onrender.com` — это и есть твой мессенджер.
   Открывай её на любом устройстве.

### Важно про бесплатный тариф Render

Free-инстанс "засыпает" после ~15 минут без запросов и просыпается
~30-50 секунд при следующем заходе — для теста с друзьями ок, для
постоянного использования позже можно перейти на платный тариф (от
нескольких долларов в месяц), тогда не будет задержки на "пробуждение".

### Данные

Сообщения хранятся в файле `data.sqlite` на сервере. На бесплатном
Render-диске файл может сбрасываться при пересборке — для постоянного
хранения на будущее стоит подключить Render Postgres (тоже есть
бесплatный tier) вместо SQLite-файла.

## Локальная проверка (если когда-то будет компьютер)

```
npm install
npm start
```
